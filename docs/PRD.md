# PRD — PharmaOS

## Problem

Small pharmacies in Bangladesh often track stock and sales on paper or spreadsheets. Owners need a simple cloud tool that works in Bangla and scales to multiple staff later.

## Users

| User | Foundation scope |
|------|------------------|
| Pharmacy owner | Sign up, create shop, log in, see dashboard shell |
| Staff | TO DECIDE — Phase 2+ |

## Goals (foundation)

- One account creates one pharmacy (tenant).
- Owner can sign up, log in, log out, and see their pharmacy name on a protected dashboard.
- Data is isolated per pharmacy (RLS).

## Non-goals (this phase)

- Medicine catalog, barcode, stock, sales, reports, AI assistant.
